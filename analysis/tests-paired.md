**输出**：`analysis/tests-paired.csv`（长表 16 行）、本文件

## 方法

- **配对键**：`prompt_id`（0–29）。同一 prompt 下取该模型文本与 Human 文本为 1 对，差值 $d_i = \text{AI}_i - \text{Human}_i$，正值为 AI 更高。四个模型各 30 对，$df = 29$。
- **配对 t 检验**：$t = \bar{d} / (s_d / \sqrt{n})$，双侧 p；**Cohen's d** 用配对口径 $d = \bar{d} / s_d$，$s_d$ 为差值样本标准差（ddof = 1），不做 Hedges 小样本校正。
- **方差齐性**：Levene 检验，比较该模型 30 篇与 Human 30 篇；主口径 `center = "median"`（Brown–Forsythe），同时给 `center = "mean"` 作对照。任一版本 p < .05 即视为不齐，并按保守口径补充非参数检验（只由主口径触发也能满足要求）。
- **非参数对照**：配对用 Wilcoxon signed-rank（双侧；scipy 默认零差值处理与 `method="auto"`，n = 30 时为正态近似），组间用 Mann–Whitney U（双侧）。这些 p 为**原始值**，未纳入 Holm 校正。
- **多重比较**：4 指标 × 4 模型 = 16 组原始 p 一起做 Holm 逐步校正，`p_holm` 已单调化，与 α = .05 比较。
- **口径**：只报描述统计与检验结果，不做因果推断；显著性不被解释为「AI 与人类存在本质差异」。

## 分指标结论

### MATTR（窗口 100）

四个模型的均值差（AI − Human）均为正，从 +0.0510（DeepSeek）到 +0.0993（Claude）。Holm 校正（16 组）后四组均仍显著：Claude（p_holm < .001）、GPT（p_holm < .001）、DeepSeek（p_holm < .001）、Kimi（p_holm < .001）。方差齐性：Brown–Forsythe 版在 Claude（p = .047）、DeepSeek（p = .037）、Kimi（p = .043）上拒绝方差齐性；均值版在 Claude（p = .016）、GPT（p = .020）、DeepSeek（p = .011）、Kimi（p = .014）上拒绝方差齐性。其中 GPT（BF p = .057）的中位数版未达显著，按均值版保守纳入补充检验。补充非参数对照：Claude（Wilcoxon p < .001，MWU p < .001）；GPT（Wilcoxon p < .001，MWU p < .001）；DeepSeek（Wilcoxon p < .001，MWU p < .001）；Kimi（Wilcoxon p < .001，MWU p < .001）。Wilcoxon 与配对 t 在 α = .05 下的显著性判断一致（均为原始 p）；Mann–Whitney U 忽略配对，只作组间参照。MATTR 固定窗口 100，对文本长度不如 TTR 敏感；Human 组跨文本方差较大，均值差与 d 应结合方差齐性结果一起看。

### MTLD

四个模型的均值差（AI − Human）均为正，从 +18.51（DeepSeek）到 +59.12（Claude）。Holm 校正（16 组）后四组均仍显著：Claude（p_holm < .001）、GPT（p_holm < .001）、DeepSeek（p_holm .006）、Kimi（p_holm < .001）。方差齐性检验两版均未拒绝：Brown–Forsythe 版 p = .178–.977，均值版 p = .152–.967，无需补非参数检验。MTLD 与 MATTR 使用不同的 token 口径（MTLD 只取字母词，剔除数字与带标点词），两者只比方向、不比绝对水平。

### 平均句长

四个模型的均值差（AI − Human）方向不一致：Claude +4.00、GPT -2.67、DeepSeek -0.83、Kimi +2.61。Holm 校正（16 组）后 Claude（p_holm < .001）、GPT（p_holm .003）、Kimi（p_holm .006） 仍显著。DeepSeek 原始与校正后均不显著（p = .181）。方差齐性：Brown–Forsythe 版在 GPT（p = .034）、DeepSeek（p = .040）上拒绝方差齐性；均值版在 GPT（p = .020）、DeepSeek（p = .021）上拒绝方差齐性。补充非参数对照：GPT（Wilcoxon p < .001，MWU p < .001）；DeepSeek（Wilcoxon p = .198，MWU p = .473）。Wilcoxon 与配对 t 在 α = .05 下的显著性判断一致（均为原始 p）；Mann–Whitney U 忽略配对，只作组间参照。平均句长的方向在四个模型上不一致，不能概括为「AI 句子更长」或「AI 句子更短」；句长依赖 spaCy 分句，缩写与省略号处可能有切分误差。

### 平均段长

四个模型的均值差（AI − Human）均为负，在 -51.41（GPT）到 -15.83（Kimi）之间。Holm 校正（16 组）后四组均不显著（p_holm = .062–.814）。方差齐性：Brown–Forsythe 版在 GPT（p = .040）上拒绝方差齐性；均值版在 Claude（p = .011）、GPT（p = .005）、DeepSeek（p = .028）、Kimi（p = .023）上拒绝方差齐性。其中 Claude（BF p = .076）、DeepSeek（BF p = .131）、Kimi（BF p = .130）的中位数版未达显著，按均值版保守纳入补充检验。补充非参数对照：Claude（Wilcoxon p = 1.000，MWU p = .404）；GPT（Wilcoxon p < .001，MWU p < .001）；DeepSeek（Wilcoxon p = .339，MWU p = .066）；Kimi（Wilcoxon p = .339，MWU p = .080）。Wilcoxon 与配对 t 在 α = .05 下的显著性判断一致（均为原始 p）；Mann–Whitney U 忽略配对，只作组间参照。平均段长受段落切分与少数超长段落影响：Human 段长 SD 约 100 词、存在极端值，均值差与 d 的稳定性弱于其他指标；本表只作描述。

## 复算核对

下面两组用纯 Python 逐项重算（不用 pandas/numpy 的均值、标准差与 t 检验），并与主表逐位比对；脚本每次运行都会执行同样检查，不一致即报错退出。

**MATTR（窗口 100） × Claude**

- 30 对差值之和 = 2.979763，均值 = 2.979763 / 30 = 0.099325
- 样本 SD（ddof = 1）：平方和 0.109727 ÷ 29 后开方 = 0.061512
- t = 0.099325 / (0.061512 / √30) = 8.8443，df = 29
- 双侧 p = 9.910e-10；d = 0.099325 / 0.061512 = 1.6147
- 与主表比对：均值差 0.0e+00、t 0.0e+00、p 0.0e+00、d 0.0e+00

**平均段长 × GPT**

- 30 对差值之和 = -1542.158885，均值 = -1542.158885 / 30 = -51.405296
- 样本 SD（ddof = 1）：平方和 322574.252313 ÷ 29 后开方 = 105.466820
- t = -51.405296 / (105.466820 / √30) = -2.6696，df = 29
- 双侧 p = 1.231e-02；d = -51.405296 / 105.466820 = -0.4874
- 与主表比对：均值差 0.0e+00、t 0.0e+00、p 0.0e+00、d 0.0e+00

**Holm 校正核对**

16 组中 MATTR（窗口 100） × Claude 的原始 p 最小（9.910e-10），Holm 第一步乘以 16：16 × 9.910e-10 = 1.586e-08，与表中 `p_holm = 1.586e-08` 一致；其余组按排序依次乘以 15、14……并做单调化。

## 口径与限制

1. **Levene 检验的是组间方差齐性**，不是配对 t 检验的正态性假设；本表按老师要求报告它，并用它决定是否补非参数对照，两者在解释上分开看。
2. 非参数 p 值未做多重比较校正；Mann–Whitney U 忽略配对关系，只作组间参照，配对设计下 Wilcoxon 更贴合。
3. 段长的均值差对少数超长 Human 段落敏感：中位差与均值差可能不同号（见下），因此段长只作描述，不据此下结论。
4. MATTR（窗口 100）与 MTLD 的 token 口径不同，两者只比方向、不比绝对水平。
5. 本表不改变 `per-text-table.csv`，也不改清洗与指标计算；所有数值可由 `python3 analysis/paired_tests.py` 重跑复现。
