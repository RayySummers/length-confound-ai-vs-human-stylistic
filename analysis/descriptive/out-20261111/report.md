> 以下为人工解读，依据 `report.md` 第 3–5 节与 `summary_by_genre.csv` / `summary_excl_degenerate.csv` 的脚本输出。**先报 alpha 口径**；只描述方向与分布，不做显著性检验、不做因果解释。正文以中位数为主，均值只作参考；涉及 llama_31_405b 温度 100 时一律用剔除退化文本后的数字，不再使用被污染的均值。

1. **MATTR（alpha）：差距不再是「AI 普遍更高」，而是因模型而异。** 人类中位数 0.735；12 个 AI 组里 10 组更高、2 组（都是 llama）更低，但只有 gpt-45（温度 0 +0.047、温度 100 +0.107）、claude（+0.044 / +0.046）和 gpt-4o 温度 100（+0.056）这 5 个组合算明显；gpt-4o 温度 0（+0.002）、gemini（+0.012 / +0.026）、deep-seek（+0.011 / +0.014）与人类基本持平；llama 温度 0 低 0.039，llama 温度 100 剔除退化后为 −0.007。按语体看，虚构类仍是 AI 更高（6 个语体的 12 组平均 +0.024 到 +0.050），说明类的 A/E/F/J 为 +0.014 到 +0.032，但 B、C 反转为人类略高（−0.013、−0.014）。

2. **MTLD（alpha）：人类 106.5，只有 gpt-4o 温度 0 与人类接近（109.6）。** 其余模型更高（119.9 到 319.9），llama 温度 0 反而更低（80.0）。温度 100 的两组仍出现成片 >300 的值（gpt-45 温度 100 有 217 篇，llama 温度 100 有 115 篇），gpt-45 温度 100 的 IQR 达 111.9；MTLD 只作方向参考，不比较绝对大小，正文一律用中位数。

3. **句长（alpha）：AI 仍然更短，但差距缩小到 0.4–4.0 词。** 人类中位数 20.4 个 alpha 词；gpt-4o、claude、gemini、deep-seek 各温度组在 16.4–17.9 之间，llama 温度 0 为 18.1，gpt-45 温度 100 为 20.0（与人类基本持平），llama 温度 100 剔除退化后为 20.3。说明类的 A/F/J 差 3.5–4.2 词，虚构类在 −2.6 到 +1.2 词之间；C（书评）由 v1 的「基本持平」变为人类长 3.6 词，R 反而 AI 长 1.2 词（n=9，需谨慎）。

5. **温度效应（alpha）：方向和 v1 一致，仍不统一。** gpt-45 从温度 0 到 100，MATTR 中位数 0.783→0.842、MTLD 158.8→319.9；gpt-4o 也明显上升（0.737→0.792、109.6→180.5）；gemini 小幅上升（0.747→0.762）；deep-seek 基本不变（0.747→0.750）；llama 温度 100 的极端值主要来自退化文本，剔除后 MATTR 0.728、MTLD 101，与温度 0 的 0.696 / 80 相比只是小幅上升，不再呈现「方差爆炸」。

## 需要老师定夺的点

- **退化阈值**：按 MATTR>0.90 或 MTLD>1000 共剔除 99 篇（llama 温度 100 95 篇、gpt-45 温度 100 4 篇）。剔除后 llama 温度 100 的 MATTR 中位数 0.728、MTLD 100.9、句长 20.3，与人类和其他模型的相对位置都更合理；阈值是否合适、是否需要人工抽查这批文本，需要老师定。
- **MTLD 的 N**：不足 100 词的 3 篇 claude 文本现在两个词汇指标都记 NA（N=373），与 MATTR 一致；但 100–400 词的文本仍会算出很高的 MTLD，读表时请以中位数和 N 为准。
- **长度不足**：gpt-4o 温度 0 有 228/376 篇不足 1000 个 alpha 词（最短 420），llama 温度 100 有 124/376 篇（最短 373）；这些篇目的窗口更短，模型间比较需要同时看词数分布。
