# 组会图表包 · 第二轮（2026-10-17）

> 内容：**14 个指标 × 双维度**（① 人机对比 ② AI 内部一致性）的非正式图表，供组会讨论用。

## 备注（解读注意）

- 全部检验为**双尾、未做多重比较校正**（老师 9/21 口径）；N=30/模型，属筛选性描述，不作确证。
- **`sentences_per_paragraph` 受段落切分影响大**（人类文本来自 Reddit，空行少 → 段数少、比值大且散）——把它当"格式敏感"指标，解释时留余量。
- **MTLD 反例延续**：唯一一个 AI 方差更大的指标（与 9/21 结论一致，仍存疑，等 N=90 复核）。
- MATTR 的 per-sample 数据不在本轮数据文件里，故缺单指标图；其统计在总览两张图中。
- 生成脚本：`analysis/metrics_extended.py`（新指标提取）、`analysis/round2_analysis.py`（统计＋作图）。图内字体统一 Inter（WSL 直读 Windows 字体目录），合集 PDF 为矢量版（无损缩放）。

- 2026-10-17 修正：效应量点阵图移除遗留的 x 等于 0 参考线（该线误落在 GPT-3.5 列，无含义）。
