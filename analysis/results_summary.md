- **Accuracy** and **Balanced Accuracy** (handles class imbalance)

- **ROC AUC** (probability-based discrimination)

- **Confusion matrix** (summed across folds)

### Caveats

1. **Small sample (N=30 prompts, 9 AI conditions):** Statistical power is limited. 
2. **Missing conditions:** MiniMax-M3, Muse-Spark-1.2-Contributor, GPT-5.6-Pro, Claude-Sonnet, Gemini-2.0-Pro are empty (no API keys / Arena manual paste pending). 
3. **DeepSeek-V4-Flash missing prompt 25** (timeout during generation).
4. **Genre:** Creative fiction (r/WritingPrompts) — may not transfer to academic or other registers.
5. **Population variance:** SD uses ddof=1 (sample SD). Sentence/paragraph variance metrics use `statistics.pvariance` (population variance within-text).
